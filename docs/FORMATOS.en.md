## Pending items

- **`staff.dat` version 1 (157 bytes per person):** this is the original 3.9.68 database. The reference only describes version 2 from the community updates (`TStaff`, 110 bytes, plus the preferences in a separate table, type 22, `TPreferences` of 52 bytes). The first fields coincide (the patcher's `YearChanger` uses birth date at +0x10, year of birth at +0x18 and contract dates at +0x3e/+0x46 in both versions). The hypothesis "version 1 = person + embedded preferences" does not add up exactly (110 + 52 − 4 = 158, not 157); the final 47 bytes are still to be mapped.
- **`colour.dat` (58 bytes) and `officials.dat` (43 bytes):** no structure in the reference. For referees, `RefereePatcher` uses current/potential ability (i16 at +30/+32) and discipline (byte at +37).
