TOP OBSTACLES (by impact)
1. Typed records stop after one hop: pointer fields return usize, so code drops back to raw offsets. match_eng.rs:2534
   `read_i8(m.pending_play_offender() + 0x27)` although match_player::SIDE = 0x27 and MatchPlayer::side() exist;
   contract_manager.rs:194 `read_usize(person.club_job() + 0xcf)` = club::MANAGER. City/Staff::nation() -> usize,
   Club::nation() -> Nation.
2. Four memory dialects coexist in one function (typed method / read_x(a + mod::F) / read_x(a + 0x..) / raw deref).
   fin_prm.rs:100-118: `read_usize(club + club::NATION)`, `read_i16(club + club::REPUTATION)` beside `nation.league_selected()`,
   then `club += 0x245` (club::SIZE exists), `(0xb63d60 + l * 72) == entry`.
3. Engine sub-structures are not modelled: players are `m + 0x4796 + 0x22d8*side + 0x1be*k` (match_man.rs:353; match_pl.rs:140
   writes 8920), the cell grid is `+ 0x21b6 + 90*(..)` re-derived at match_pl.rs:131 and match_eng.rs:4173, 5225, 8032.
4. Event/commentary ids are bare hex: ~309 `0x20xx/0x21xx` in match_eng.rs (2541 `narrate(call, 0x20f0, ..)`; league.rs:89-127 0x2171/0x2120).
5. Everything is `unsafe fn` with no SAFETY contract and 130 `static mut`; no way to tell which invariants matter.
6. Inline transmutes duplicating existing wrappers: contract_manager.rs:180 (exe::scout_manager_sync_scout_lists exists),
   fin_prm.rs:92 (exe::key_nation_index_of_club exists), match_pl.rs:1430 (exe::is_undisputed_action_code).
7. Doc headers still narrate the disassembly: league.rs:63-73 ("With +0x8ebb ... average of +0x1b ... strength (+0x80)"),
   club_records.rs:80-84 ("[0xae23bc], 0x6e bytes"); match code lives in league.rs (comment_standing_with).
8. Portuguese locals mixed into English code (match_man.rs:158-176, league.rs:85-91), plus `[pt]` blocks double every header.

INCONSISTENT

- competition::REPUTATION exists but club_records.rs:135 reads `+ 0x69` with a hand-written 0x6b stride.
- Typed constants used half-way: `(m.restart_type() as u8) != restart::OPEN_PLAY as u8` casts on both sides.
- Comparer/log names Portuguese while routine names are English.

GOOD
- routines! macro (motor.rs:43) ended the parallel tables; each hook is one line. detours.rs/comparison.rs are clean, English, small.
- exe_calls.rs: typed wrappers with `impl Addr` remove most call-site transmutes; records.rs gives named, typed fields.
- match_codes.rs is excellent: named constants with meaning and confidence (verified/read/inferred); used 58x in match_eng.
- Headers state what a routine does and its original address; branch()/mutation markers make the test harness legible.
